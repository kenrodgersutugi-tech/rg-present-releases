Installing the downloaded file

  1. Open the file from your Downloads folder — it is called RG-Present-Setup.exe.
  2. Windows will warn you. Click More info, then Run anyway. The note below explains why.
  3. Choose where to install it — the default suits almost everyone — and wait about a minute.
  4. Plug in the projector and press Windows + P, then choose Extend.
  5. Open RG-Present, press Output at the top right, and the slides appear on the projector.

The Windows warning

“Windows protected your PC”

You will see this blue box the first time you run the installer. It does not mean anything is wrong with the download — it means the installer is not yet signed with a paid certificate, so Windows has not seen enough copies of it to recognise it.

Click More info, check that the file name matches the one you downloaded, then click Run anyway. If you would rather not see the warning at all, install it from the Microsoft Store instead: that copy is signed by Microsoft.

Only ever download RG-Present from this page or from the Microsoft Store. If you want to be certain the file reached you whole, its checksum is below.
